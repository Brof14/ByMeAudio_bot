# 🎙 ByMeAudio Bot

Быстрый, полностью бесплатный и безлимитный Telegram-бот для мгновенного перевода в текст:
- 🎙 **Голосовых сообщений** (`.ogg` / Opus)
- 📹 **Видео-кружков** (`.mp4` / Video Notes)
- 🎵 **Аудиофайлов** (MP3, WAV, M4A, FLAC, AAC, OGA)
- 🎬 **Видеофайлов** (MP4, MOV, MKV — извлечение звука)

Никаких оплат, тарифов, подписок и ограничений по количеству переводов!

---

## ⚡ Особенности и возможности

- **100% Бесплатно навсегда:** вся система оплат (ЮKassa, Telegram Stars, балансы, лимиты) удалена.
- **Поддержка кружков:** автоматическое извлечение звука из Telegram видео-сообщений через FFmpeg за доли секунды.
- **Качественное распознавание:**
  - **Faster-Whisper (локально):** работает автономно без интернета/API ключей, расставляет знаки препинания, заглавные буквы, фильтрует тишину.
  - **Groq Cloud Whisper (опционально):** если в `.env` указан `GROQ_API_KEY`, бот переводит аудио на модели Whisper-Large-v3-Turbo со скоростью ~0.3–0.8 секунды!
  - **Google Speech (резервный):** автоматический fallback.
- **Поддержка длинных аудио:** бот аккуратно разбивает длинные расшифровки на части (лимит Telegram 4096 символов не нарушается), а при объёме более 10 000 символов прикрепляет файл `.txt`.
- **Неблокирующая архитектура:** обработка аудио и видео вынесена в отдельные потоки, бот не зависает для других пользователей.
- **Статистика:** подсчёт персональной статистики по каждому пользователю (`/stats`) и сводная статистика для администраторов.
- **Рассылка:** администраторы могут делать рассылку объявлений по пользователям бота командой `/broadcast <текст>`.

## 🛠 Установка и запуск

### 1. Требования
- Python 3.10+
- FFmpeg (в Linux: `sudo apt install ffmpeg` или `sudo pacman -S ffmpeg`)

### 2. Установка зависимостей

В виртуальном окружении:
```bash
# Создание venv (если не создано)
python3 -m venv venv
# или через uv:
# uv venv venv

# Активация
source venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 3. Настройка `.env`
Создайте или отредактируйте файл `.env`:
```ini
# Токен бота от @BotFather (обязательно)
BOT_TOKEN=ваш_токен_бота

# Telegram ID администраторов через запятую
ADMIN_IDS=12345678, 87654321

# (Опционально) Бесплатный ключ Groq для мгновенного Whisper Large v3 (console.groq.com)
# Если пусто — используется встроенный локальный Faster-Whisper
GROQ_API_KEY=
```

### 4. Запуск бота
```bash
python bot.py
```
или с использованием venv:
```bash
./venv/bin/python bot.py
```

## 📱 Команды бота

- `/start` — Главное меню с описанием и кнопками навигации.
- `/help` — Подробная инструкция по отправке голосовых и кружков.
- `/stats` — Ваша статистика переводов (и статистика бота для администраторов).
- `/broadcast <сообщение>` — *(Только для админов)* Рассылка сообщения всем пользователям бота.
